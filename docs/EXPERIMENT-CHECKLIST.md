# 租卡前与每次实验检查单

本文件尚未构成租卡授权。未填写并核验的条目不得视为通过。

## 开通前

- [ ] 用户授权的供应商、机型、小时价格、总预算、起止时间、管理员联系人已记录。
- [ ] 精确资源：四台每台八张 H100，显存规格、NIC/HCA 数量/速率、IB 或 RoCE 互联拓扑与共享存储均已确认。
- [ ] 确认租用方允许的故障注入范围，尤其链路变更与节点终止；禁止触及其他租户或生产服务。
- [ ] 选择 Slurm + Pyxis/Enroot 或 K8s + Kueue，填写主机/IP、管理节点与存储配置。
- [ ] 驱动、CUDA、NCCL、OFED、调度器、运行时、Operator 版本与镜像 digest 已锁定。
- [ ] 所有模型、训练数据、留出集、trace、上游工具均以 revision/commit/hash 锁定；许可及所需下载权限已确认。
- [ ] 本地 CPU/单卡单元测试与集成测试先通过；任何跳过测试须注明实际缺项。
- [ ] 计费节点有自动截止时间；清理命令经过审查，资源列表由本实验创建记录产生。

## 每次实验清单

- [ ] 写明实验 ID、目标、seed、Git commit、配置 hash、数据路径、容器 digest 和实际软件/硬件版本。
- [ ] 写明 baseline 与 candidate 唯一变化、相同 GPU 数/预算/输入条件、预热与测量窗口。
- [ ] 预先排好同条件交替 baseline/candidate 至少三轮，输出原始每轮值、中位数、最小值和最大值。
- [ ] FP8 同时记录留出集 BF16/FP8 精度与精度差；不得只报告吞吐。
- [ ] 训练与留出题目按题目内容 hash 去重，隐藏测试对模型不可见。
- [ ] trace 回放记录计划/实际发送时间，发送滞后超限的整轮结果作废。
- [ ] 健康检查通过后才启动长跑，训练每五十步检查 step time，连续异常执行告警。

## 停机条件（租卡前填具体数值）

- 费用达到批准上限或到截止时间，立即停止工作负载并清理本次创建的计费资源。
- 节点基线、GPU/NIC 自检、版本或拓扑不符，停止扩展实验并保留失败证据。
- 无 checkpoint、无回滚路径或故障注入超过租用方允许范围，不执行故障。
- 数据泄漏、policy_version 错配、奖励测试可被修改、无法核对请求总数，停止该轮并诊断。
- 没有真实测量、精度数据缺失、回放客户端滞后超限，该轮不得进入最终结论。

## 结束

- [ ] 所有原始日志、配置、版本、时间戳、重跑命令和图表来源进入 docs/evidence。
- [ ] 区分 CPU/mock/单卡/多机证据，失败与作废轮次也保留。
- [ ] 停止并核对全部计费节点、磁盘、IP、对象存储与服务；不删除非本次实验资源。
